Сайт кафе «Уют» — архив для загрузки на хостинг
================================================

Внутри:
  index.html          — страница
  assets/             — стили, скрипт, шрифт и картинки (обязательно рядом!)

Как выложить
------------
1. Распакуйте архив в КОРЕНЬ сайта: обычно это public_html, www или htdocs
   (там, где уже лежит index.html).
2. В итоге на сервере должно быть так:
      <корень сайта>/index.html
      <корень сайта>/assets/style.css
      <корень сайта>/assets/fonts/onest.css
      <корень сайта>/assets/img/hero.svg
      ... и остальные файлы из assets/
3. Не переименовывайте папку assets и сохраняйте регистр имён:
   на Linux-хостинге Assets и assets — разные папки.
4. Откройте сайт и обновите страницу с очисткой кэша (Ctrl+F5).

Как проверить, что всё на месте
-------------------------------
Откройте в браузере два адреса:
  https://ваш-домен/assets/style.css     — должен открыться код CSS
  https://ваш-домен/assets/img/hero.svg  — должна открыться картинка
Если вместо этого 404 — папка assets не загружена или лежит не рядом с index.html.

Не нужны на хостинге: _tools/, logs/, *.md, *.ps1, freellmapi/, hello.html.
